# thib336.github.io

Personal academic website of Thibaut Plassot Sansans, hosted on GitHub Pages: https://thib336.github.io/

## Files

- `index.html` — the whole site (content, styles and a small script for the mobile menu)
- `photo.jpg` — profile photo
- `Resume_Plassot.pdf` — CV linked from the site
- `Publication_List.pdf` — publication list linked from the site
- `favicon.svg` — browser tab icon

## How to update

1. Edit `index.html` (each section is marked with a `<!-- ===== NAME ===== -->` comment).
2. Replace the PDFs when the CV or publication list changes (keep the same file names).
3. Commit and push to `master`; GitHub Pages redeploys automatically within a minute or two.
